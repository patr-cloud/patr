# frontend/CLAUDE.md

The Patr dashboard. **SolidJS + SolidStart (vinxi)** — _not Leptos_ (README/ARCHITECTURE historically said Leptos; that's fixed, but ignore any Leptos references you find). The accurate deep reference is `.github/copilot-instructions.md` at repo root. See root `CLAUDE.md` for workspace-wide rules.

## Stack

SolidJS 1.9, SolidStart/vinxi (Vite), TanStack Solid Router (file-based routing) + Solid Query (server state), TailwindCSS v4, chart.js. pnpm (pinned `11.1.1`), Node ≥22. SSR is on by default — keep it.

## Structure

- `src/routes/` — file-based routes. `_logged-in/` is auth-guarded (`beforeLoad` redirect); route-local components go in a `-components/` subdir (the `-` prefix excludes them from routing); a trailing `_` opts out of layout nesting.
- `src/components/` — reusable components, exported through the `components/index.tsx` barrel. **Import from `~/components`, never deep paths.**
- `src/hooks/` — `state-hooks.tsx` (auth/workspace context), `actions.tsx` (async action wrappers), `query-keys.ts` (centralized query-key factories), `hooks/fetch/*` (one file per domain).
- `src/bindings/` — **generated** from Rust `models` via ts-rs. Only `index.ts` + `.gitkeep` are committed; the rest is gitignored.
- Path alias `~/*` → `./src/*`.

## Generated files — never hand-edit

- `src/routeTree.gen.ts` (regenerated by `tsr generate`, run as part of `pnpm typecheck`/`build`).
- `src/bindings/*` — regenerate with `cargo bindings` (from repo root) after changing `models`. Stale bindings = CI failure.

## Conventions

- **Prettier: tabs**, tabWidth 4, printWidth 120, double quotes, semicolons, `trailingComma "es5"`. Lint via **`pnpm lint:check`** / `pnpm lint` (fix) — never invoke eslint directly.
- Props typed `MaybeAccessor<T>`; **never destructure props** (breaks reactivity — eslint `solid/no-destructure`); defaults via `mergeProps()`.
- **Styling is encapsulated in components** — callers pass semantic props (`color`, `variant`), not Tailwind classes. If you're copying Tailwind classes between call sites, make a component. Design tokens live in the `@theme {}` block in `src/app.css` (Tailwind v4, no config file).
- Reuse existing primitives before making new ones: `Button`, `Input`, `Table<T>`, `Modal`/`DeleteModal`, `PageContainer`, `Toast`, `Tooltip`, `StatusBadge`, etc.
- Data: cookie auth (`credentials: "include"` — don't attach bearer tokens manually). `httpRequest<T>` (`utils/http-request.ts`) returns a discriminated `FetchResult<T>` and handles 401 refresh + SSR cookie forwarding. Queries use `createQuery` + a key from `query-keys.ts`; mutations use the wrappers in `hooks/actions.tsx`.
- `console.log` is fine — the production build strips it (`esbuild.pure`). Don't flag it as cleanup.
- **JSX whitespace: use `&nbsp;`, not `{" "}`.** Prefix unused variables with `_`.

## Cloud vs self-hosted

Build-time gating via `VITE_CLOUD_MODE` (default off; cloud CI sets `VITE_CLOUD_MODE=true`). Everything routes through `src/utils/env.ts`:

- `IS_CLOUD` — build-time boolean constant (`import.meta.env.VITE_CLOUD_MODE === "true"`).
- `BASE_DOMAIN` / `DEPLOYMENT_DOMAIN` / `REGISTRY_DOMAIN` — default to the SaaS domains only when `IS_CLOUD`, else read from `VITE_*` env or stay `undefined` (UI hides domain-dependent surfaces).
- `cloudOnly<T>(config)` — wraps a TanStack route options object; on self-hosted returns a stub whose `beforeLoad` throws `notFound()`, so the route 404s. Use this for cloud-only route files, not conditional imports or regex hacks.

**Tree-shaking rules** (this is the part that bites):

- `{IS_CLOUD && <Foo />}` **drops** `<Foo />` from the self-hosted bundle. `<Show when={IS_CLOUD}>` does **not** — don't use it for cloud gating.
- For orphan components, gate a `lazy()` import on `IS_CLOUD` so the chunk never enters the main bundle. For event handlers, use a ternary at the definition site (`const handle = IS_CLOUD ? async () => {…} : undefined`).

Currently gated: Turnstile widget + script, "Continue with GitHub" buttons + `/login/github` `/sign-up/github` `/profile/github/callback` routes, Profile → Connected Accounts, the "Patr Registry" deploy option + registry image-name prefix, and domain hints. **Gotcha:** the `cfTurnstileToken` request field is `String` (not `Option`) with a `min-length` preprocess, so send `"self-hosted"` as a placeholder — the server's validation is `cfg`-gated and ignores it.

## Commands (from `frontend/`)

- `pnpm dev` — dev server on port 3030 (override with `PORT`). Or reach it via `cargo api`.
- `pnpm build` (self-hosted) / `VITE_CLOUD_MODE=true pnpm build` (cloud); `pnpm typecheck` (`tsr generate && tsc --noEmit`), `pnpm lint:check`, `pnpm format:check`.
- Env via `import.meta.env.VITE_*` (`VITE_BASE_URL`, etc.); see `.env.example`.

## Design

Brand palette lives in the `@theme {}` block in `src/app.css` (Tailwind v4 tokens) — use the semantic names, not raw hex:

- Primary `#f89b41` (orange); secondary `#0d0526` (darkest) → `-dark #191131` / `-medium #2e2450` / `-light #23203e`.
- Status: error `#d62b36`, warning `#fdd13a`, success `#47c96c`, info `#007bff` (each with `-dark` / `-light` variants).
